안녕하세요, 첫 글입니다

2026년 8월 20일 #소개 #블로그

이 블로그는 마크다운 파일을 작성하면 빌드 스크립트가 이를 읽어 정적인 HTML 페이지로 변환해주는 구조입니다. React나 Vue 같은 프레임워크 없이, 순수 HTML/CSS/JavaScript만으로 동작합니다.

이 블로그의 특징

  • 마크다운으로 글쓰기 → 빌드 → 정적 사이트 생성
  • 다크모드 지원 (시스템 설정 자동 감지 + 우측 상단 버튼으로 수동 전환)
  • 모바일에서도 읽기 편한 반응형 레이아웃

코드 블록 예시

function greet(name) {
  return `안녕하세요, ${name}님!`;
}

console.log(greet('세상'));

인용문도 이렇게 스타일이 적용됩니다. 읽기 편한 것이 최우선 목표입니다.

앞으로 content/posts/ 폴더에 마크다운 파일을 추가하고 npm run build (또는 npm run dev)만 실행하면 새 글이 자동으로 목록에 나타납니다.
