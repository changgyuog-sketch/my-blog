새 글은 이렇게 작성하세요

2026년 8월 25일 #가이드

새 글을 추가하는 방법은 간단합니다.

  1. content/posts/ 폴더에 YYYY-MM-DD-제목.md 형식으로 파일을 만듭니다.
  2. 파일 맨 위에 아래처럼 프론트매터를 작성합니다.
---
title: "글 제목"
date: "2026-08-25"
tags: ["태그1", "태그2"]
description: "목록 페이지에 보여줄 한 줄 설명"
---
  1. 그 아래에 본문을 마크다운으로 씁니다.
  2. npm run build를 실행하면 dist/ 아래에 정적 HTML이 생성됩니다. 개발 중에는 npm run dev를 실행해두면 파일을 저장할 때마다 자동으로 다시 빌드됩니다.

목차 삼아 정리하면

단계 명령어
의존성 설치 npm install
빌드 npm run build
개발 서버 + 자동 재빌드 npm run dev

이 표처럼 표(table), 목록, 코드블록, 인용문 등 기본적인 마크다운 문법을 모두 지원합니다.
